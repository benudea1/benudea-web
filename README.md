# BeNudea — Web oficial

Web prototipo de BeNudea Nutricosmetics, marca de nutricosmética consciente.
Complementos alimenticios formulados con criterio, sin excipientes innecesarios.

**Producto en preventa**: Be-C Complex — Vitamina C con PureWay-C® y minerales Albion® Minerals.

## Sobre este repositorio

Sitio estático (HTML + CSS + JS vanilla, sin build). Se despliega en Vercel con dominio custom `www.benudea.com`.

- `index.html` — landing principal con las secciones: hero, la piel como espejo, por qué BeNudea, nuestro método, producto (Be-C Complex), sobre nosotros, blog, FAQs, contacto
- `guia-etiquetas-suplementos.html` — primera entrada del blog: "Cómo leer y entender una etiqueta de complementos alimenticios"
- `sitemap.xml` + `robots.txt` — SEO
- `LOGOTIPOS BENUDEA_*.svg` — sistema de logos oficial
- `Amazon - imágenes listing_v03/` — imágenes del listing Amazon (usadas en carrusel producto)
- `Frases destacadas_01/` — brand-observation images con las citas destacadas
- `iconos-razones/` — iconos naranjas de "Es para ti si..."
- `imagenes blog 1_01/` — imágenes editoriales del blog
- `logos-patentes/` — logos oficiales PureWay-C® y Albion® Minerals

## Deploy

Push a `main` → Vercel deploya automáticamente. HTTPS gestionado por Vercel.
